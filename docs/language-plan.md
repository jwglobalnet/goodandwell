# 추가 언어 기획

작성: 2026-11, 갱신: 2026-11 (프랑스어·번체 추가). 근거 자료는 2021 회사소개서(품목별 주요 수출국), 2014 다국어 카탈로그(불·러·태), 기존 홈페이지(국·영·중·일)다.
시장 규모나 관세 같은 외부 수치는 넣지 않았다. 실제로 추진할 때 따로 확인한다.

## 현재 언어

| 언어 메뉴 표기 | 경로 | 대상 |
|---|---|---|
| English | `/en/` | 기본. 유럽·이스라엘·미국·호주 등 영어로 거래하는 바이어 전체 |
| Français | `/fr/` | 프랑스(구운김 현재 수출국), 벨기에, 스위스, 캐나다 퀘벡 |
| 日本語 | `/ja/` | 주력 시장 일본 |
| 한국어 | `/ko/` | 국내 관계자, 한국계 바이어 |
| 简体中文 | `/zh/` | 간체 사용자 (중국 본토, 싱가포르·말레이시아) |
| 繁體中文 | `/zh-hant/` | 번체 사용자 (대만, 홍콩, 마카오, 해외 화교) |

- 언어 메뉴는 각 언어 사용자가 자기 언어로 읽는 이름(엔도님)으로 표기한다. 국기와 국가명은 쓰지 않는다.
- 중국어는 **나라가 아니라 글자체(간체·번체)로 나눈다.** "대만", "중국" 같은 국가명이 메뉴에 나오지 않으므로 어느 쪽 사용자에게도 정치적으로 문제가 되지 않는다. 대형 국제 사이트들이 흔히 쓰는 방식이다.
- 번체는 간체 문구를 빌드할 때 자동 변환(OpenCC, 글자만 변환하고 지역 어휘는 바꾸지 않음)해서 만든다. 문구를 따로 관리할 필요가 없고, 간체를 고치면 번체도 같이 바뀐다.
- 중국어 페이지 본문에도 특정 지역명이 들어가지 않게 했다. 예를 들어 About의 수출국 목록에서 대만을 뺐다. 다른 언어 페이지에는 그대로 둔다.
- 남은 확인: 중국어·프랑스어 문의에 답할 사람이 있는지(지금은 "영·일·한으로 답변"이라고 쓰고 노란 표시), 원어민 검수.

## 고르는 기준

1. **실제 거래가 있거나 있었는가**: 2021 소개서의 품목별 수출국, 지난 카탈로그를 만든 언어
2. **바이어가 영어로 충분한가**: 수입상은 대개 영어를 쓴다. 현지어 페이지는 "우리를 이 시장 파트너로 본다"는 신호이고, 검색에서 현지 바이어가 찾게 해 준다.
3. **인증·규제가 맞는가**: FSSC 22000은 유럽 유통사가 중시하는 인증이다. 할랄 인증이 없으면 중동·인도네시아는 뒤로 미룬다.
4. **만들고 유지하는 비용**: 오른쪽에서 왼쪽으로 쓰는 문자(히브리어, 아랍어)는 레이아웃 작업이 따로 필요하다. 그 언어로 온 문의에 누가 답할지도 함께 정해야 한다.

## 언어마다 만들 페이지 (라이트 버전)

새 언어는 전체 사이트가 아니라 바이어가 실제로 보는 페이지만 만든다.

| 페이지 | 포함 | 이유 |
|---|---|---|
| Home | 예 | 첫인상, 숫자, 제품, OEM 5단계, 문의 폼 |
| Products 목록·상세 | 예 | 규격표는 데이터라 번역할 것이 이름·설명·라벨 정도 |
| Factory & Quality | 예 | 인증(FSSC 22000, HACCP, 원산지인증수출자)이 유럽 바이어에게 중요 |
| About | 아니오 | 영어 페이지로 연결 |
| News | 아니오 | 영어 소식만 운영 |

프랑스어 Home에는 원산지인증수출자(한-EU FTA 원산지 신고와 관련)를 눈에 띄게 둔다. 유효 여부를 확인한 뒤에.

## 언어권마다 다른 구성으로 바꾸기

가능하다. 지금은 모든 언어가 같은 틀(`src/pages/[lang]/...`)을 쓰지만, 단계적으로 바꿀 수 있다.

1. **문구만 다르게**: 지금 방식. 같은 구조에 언어별로 다시 쓴 문구
2. **섹션 순서·노출을 다르게**: 언어별 설정 하나로 Home 섹션의 순서와 노출을 바꾼다. 예: 일본어는 OEM·품질을 앞에, 프랑스어는 원산지인증수출자·FSSC 22000을 앞에
3. **페이지를 통째로 다르게**: `src/pages/fr/index.astro`처럼 그 언어 전용 파일을 만들면 그 언어만 별도 페이지가 된다. 나머지 언어는 공통 틀을 그대로 쓴다

제품 규격표와 회사 정보는 공통 데이터라서, 구성을 바꿔도 숫자는 한 곳만 고치면 모든 언어에 반영된다.

6. 문의 폼 제목에 언어 코드를 넣어 어느 언어 페이지에서 온 문의인지 구분(이미 적용됨)
